# BIBLIOTECA

>Aplicação desenvolvida para gerenciamento de acervo, controle de estoque e registro de devoluções.
## Sobre o Projeto
Este projeto é um **Trabalho Avaliativo Discente** desenvolvido para a disciplina de **[Algoritmos e estrutura de dados II]**. O objetivo principal é aplicar na prática conceitos de manipulação de estruturas de dados através de um sistema funcional de biblioteca, 
permitindo localizar obras com eficiência, filtrar registros específicos e organizar o acervo sob diferentes critérios.


## Funcionalidades

* ** Livros em Estoque:** Listagem completa do acervo disponível, com controle de quantidade de exemplares e status de disponibilidade.
* ** Controle de Devoluções:** Registro e atualização de entrada de livros devolvidos, recompondo automaticamente o saldo em estoque.
* ** Integrantes:** Exibição das informações da equipe responsável pelo desenvolvimento do sistema diretamente na interface/menu da aplicação.
